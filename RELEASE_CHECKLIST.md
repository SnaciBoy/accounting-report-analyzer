# Подготовка публикации

- Указать ФИО автора в CITATION.md.
- Выбрать лицензию и добавить её точный текст в LICENSE.
- Создать репозиторий, например akkond-financial-analysis, и загрузить
  содержимое этой папки с сохранением вложенной .github/workflows.
- Проверить результат workflow Tests. Локальные тесты не подтверждают
  успешный запуск на серверах GitHub.
- На Windows проверить новые INSTALL.bat и START.bat. Расчётное ядро уже
  запускалось участником; новые скрипты окружения требуют отдельной проверки.
- Зафиксировать тег версии и создать Release с описанием состава.
- Заменить шаблон адреса в CITATION.md реальной ссылкой на тег и указать автора.
- В статье использовать ссылку на конкретный выпуск и фактическую дату обращения.

Подготовка файлов не означает, что репозиторий или выпуск уже опубликованы.
Для публичной загрузки используйте исходные отчёты из reports только после
проверки состава публикуемых файлов. Личные документы исследования и
результаты замеров в эту папку не включены.
