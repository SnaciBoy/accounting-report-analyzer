# Анализ бухгалтерской отчётности на Python

Учебно-исследовательская программа для анализа годовых XLSX из Ресурса БФО ФНС.
Пример — АО «АККОНД», ИНН 2126000147, отчётность за 2023–2025 годы.
Версия расчётного ядра: **2.0.2**. Программа создаёт Excel-книгу с коэффициентами,
динамикой, структурой, проверками баланса и ссылками на исходные ячейки.

## Быстрый запуск в Windows

1. Установите Python 3.10 или новее с pip, если его ещё нет.
2. Скачайте и распакуйте проект целиком в доступную для записи папку.
3. Дважды нажмите `INSTALL.bat` и дождитесь завершения установки зависимостей.
4. Запустите `START.bat`.
5. Откройте `results/Анализ_АККОНД.xlsx`.

Установщик создаёт окружение `.venv` внутри проекта. Сначала проверяет
`py -3`, затем найденные в PATH команды `python` и `python3`. Требуются
Python 3.10+, модули `venv` и `ensurepip`. Проверяется путь каталога скриптов Windows (Scripts); установки с другой структурой
(например, отдельные сборки MSYS2) пропускаются. Перед созданием окружения
выводятся выбранный интерпретатор и его версия. Диск и расположение Python в программе не зафиксированы.
Установка зависимостей требует подключения к интернету. После установки
анализ выполняется локально, без доступа к сайту ФНС.

В PowerShell эти же файлы запускаются так:

```powershell
.\INSTALL.bat
.\START.bat
```

Перед повторным анализом закройте выходную книгу в Excel. В случае ошибки
старый результат сохраняется и не считается новым. Время в консоли —
чтение, расчёты и запись, без действий пользователя и проверки человеком.

## Linux и macOS

Из корневой папки проекта выполните:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python analyze.py
.venv/bin/python -m unittest -v
```

В некоторых установках Linux модуль создания окружения устанавливается
отдельно средствами дистрибутива. BAT-файлы предназначены для Windows.

## Если Python не найден

Откройте новый терминал после установки Python. Если используете несколько
установок или Python не добавлен в PATH, укажите полный путь к выбранному
`python.exe` только для установки окружения. В PowerShell:

```powershell
$env:PYTHON_EXE = Read-Host "Полный путь к python.exe без кавычек"
.\INSTALL.bat
```

Путь вводится на вашем компьютере и не записывается в исходный код.
Указанный вручную интерпретатор имеет приоритет при создании окружения.
Если `.venv` уже существует, используется оно; для смены интерпретатора
сначала переименуйте `.venv` и повторите установку. Не переносите готовое
окружение между компьютерами — создавайте его заново через INSTALL.bat.

## Проверенные условия

Расчётное ядро запускалось участником на Windows 11, Anaconda Python 3.14.6
и openpyxl 3.1.5. Поиск Python и проверка структуры окружения подготовлены для разных путей
установки, но требует отдельной проверки в Windows. Поддержка всех
дистрибутивов и установок Python не заявляется.

## Исходные отчёты

В `reports/` включены три XLSX, предоставленные для исследования из выгрузки
[Ресурса БФО ФНС](https://bo.nalog.gov.ru/). Происхождение и контрольные суммы
описаны в [DATA.md](DATA.md). Отчёты не подменяются вручную набранными суммами.

Для своих данных сначала извлеките XLSX из ZIP ФНС. Нужны минимум два
годовых отчёта одной организации, по одному выбранному файлу на каждый год.
Формат: листы «Сведения об организации», «Бухгалтерский баланс» и
«Отчет о финансовых результатах»; единица измерения — тыс. руб.
ZIP, PDF, XLS напрямую не поддерживаются. Новые формы выгрузки могут
потребовать изменения импортера. Скачивание с сайта не автоматизировано.

```console
python analyze.py --reports my_reports --inn 1234567890 --output results/analysis.xlsx
```

Годы определяются по заголовкам, показатели — по кодам строк. Каждый год
берётся из текущего столбца своего годового отчёта. Сравнительные значения
девяти используемых строк сверяются между файлами: при конфликте анализ
останавливается. Остальные статьи отчётности не сверяются.

## Расчёты

| Показатель | Формула по кодам строк | Единица |
| --- | --- | --- |
| Доля оборотных активов | 1200 / 1600 × 100 | % |
| Текущая ликвидность | 1200 / 1500 | коэффициент |
| Финансовая автономия | 1300 / 1600 | коэффициент |
| Чистая рентабельность продаж | 2400 / 2110 × 100 | % |

Вычисления выполняются через `Decimal`. В Excel сохраняются числовые
результаты с отображением двух знаков, без предварительного округления
до двух знаков. После преобразования в число Excel точность ограничена
его числовым представлением. Это значения, а не пересчитываемые формулы:
после изменения исходников повторно запустите программу.

При нулевом знаменателе выводится «н/р». Явный прочерк в исходном отчёте
считается нулём; пустая обязательная ячейка вызывает ошибку.
Для динамики темп прироста считается только при положительной базе.

Три проверки на каждый год: 1600 = 1700; 1600 = 1100 + 1200;
1600 = 1300 + 1400 + 1500. Допуск — 2 тыс. руб., это принятое в программе
правило проверки округлённых сумм, а не универсальный норматив ФНС.
Статус OK подтверждает эти равенства в пределах допуска, но не достоверность
отчётности и не правильность всех коэффициентов.

## Проверка воспроизводимости

`python -m unittest -v` запускает 12 тестовых методов: 27 исходных значений,
12 коэффициентов, числовой экспорт и происхождение данных, конфликт
сравнительных значений, пропуск ячейки/кода/файлов, другой ИНН или единица,
повтор года, нарушение баланса, нулевой знаменатель и отрицательная прибыль.
Тесты копируют отчёты во временную папку и не изменяют оригиналы.
Workflow в `.github/workflows/tests.yml` запускает эти проверки на GitHub;
до первого фактического запуска его результат не установлен.

Для трёх лет контрольные коэффициенты при отображении двух знаков:

| Год | Доля оборотных активов, % | Текущая ликвидность | Автономия | Чистая рентабельность, % |
| --- | --- | --- | --- | --- |
| 2023 | 71,74 | 2,83 | 0,73 | 14,05 |
| 2024 | 72,84 | 5,20 | 0,85 | 15,07 |
| 2025 | 73,81 | 4,95 | 0,84 | 15,46 |

Совпадение этих значений с контрольным Excel относится к проверенному
набору данных и не доказывает отсутствие ошибок на любых входных файлах.

## Использование в статье

Для фиксации версии и ссылки на код используйте [CITATION.md](CITATION.md).
Ключевые функции для краткого листинга: `divide`, `indicators`, `balance_checks`.
Полный код импортера и экспорта доступен в `analyze.py`.
Время обработки и затраты разработки нельзя выводить из числа строк кода:
полный пользовательский цикл измеряется отдельно.
