# История изменений

## Исправление выбора Windows Python

Добавлена проверка каталога скриптов Scripts при выборе интерпретатора. Установки
с другой структурой пропускаются; путь выбранного Python выводится в консоль.
Существующее несовместимое окружение не изменяется автоматически.
Новая проверка требует подтверждения на Windows.

## Общий запуск

Убрана привязка инструкции к личному пути Anaconda. Windows-установщик
перебирает доступные интерпретаторы, пропускает установки без venv/ensurepip
и создаёт локальное окружение. START.bat проверяет окружение перед запуском.
Расчётное ядро 2.0.2 и исходные отчёты не изменены.


## Подготовка репозитория

Расчётное ядро 2.0.2 и 12 тестовых методов сохранены без изменений.
Добавлены README, сведения об исходных данных с SHA256, инструкция
цитирования, исключения Git и workflow тестирования. Windows-скрипты
теперь используют локальное окружение и позволяют явно выбрать Python.
Старое CSV-ядро, личные замеры, журнал разработки и готовые результаты
не включены в этот отдельный выпуск.

## 2.0.2

Чтение отчётов ФНС, четыре коэффициента, баланс, динамика и структура,
экспорт в XLSX с источниками и двумя диаграммами. Уточнены подписи,
отступы и цвета диаграмм.
